- Remote desktop graphics use the host's modern codecs (H.264, decoded by the Mac's own hardware decoder) when it offers them, and reach the screen with far less copying. Resizing a window scales the picture at once, asks for the new size as soon as you let go, and no longer flashes black. If a host misbehaves, switch off **View ▸ Remote Desktop ▸ Fast Graphics** and reconnect.
- The clipboard is shared with remote desktops: copy and paste text in both directions, and paste files and folders copied on your Mac into the remote desktop. The Mac's clipboard is only shared with the remote desktop you are working in. **View ▸ Remote Desktop ▸ Share Clipboard** turns it off.
- **View ▸ Remote Desktop ▸ Retina Resolution**: switch it off for a desktop with a quarter of the pixels, which is quicker on slow links.
- Choosing a credential now has a search field: type part of a name, username or folder and everything else is hidden.
- The sidebar no longer repeats everything in "All Connections" and "All Credentials" lists; the filter field searches the whole tree.
